   - Si « $>$ » : Même dénominateur : on compare les numérateurs ($2 < 5$), donc $\dfrac{2}{5} < \dfrac{5}{5}$.

2. b) $\dfrac{24}{25} \;\square\; 1{,}06$ → attendu : $<$ (options : $<$ / $=$ / $>$)

   - Si « $=$ » : $1{,}06 = \dfrac{106}{100}$ (on lit les centièmes). Au dénominateur $100$ : $\dfrac{24}{25} = \dfrac{96}{100}$ et $\dfrac{106}{100}$, donc $\dfrac{24}{25} < 1{,}06$.
   - Si « $>$ » : $1{,}06 = \dfrac{106}{100}$ (on lit les centièmes). Au dénominateur $100$ : $\dfrac{24}{25} = \dfrac{96}{100}$ et $\dfrac{106}{100}$, donc $\dfrac{24}{25} < 1{,}06$.

   - Si « $<$ » : $\dfrac{1}{3} = \dfrac{1 \times 5}{3 \times 5} = \dfrac{5}{15}$ : on a multiplié le numérateur et le dénominateur par $5$, donc $\dfrac{1}{3} = \dfrac{5}{15}$.

> Méthode : même dénominateur, puis on compare les numérateurs.  

Réponse : $-\dfrac{1}{6} > -\dfrac{2}{3}$ ; $\dfrac{24}{25} < 1{,}06$ ; $\dfrac{1}{3} = \dfrac{5}{15}$

1. a) $\dfrac{9}{11} \;\square\; \dfrac{9}{7}$ → attendu : $<$ (options : $<$ / $=$ / $>$)
   - Indice : Même dénominateur : compare les numérateurs. Même numérateur : la plus grande a le plus petit dénominateur. À 1 : compare le numérateur au dénominateur.
   - Si « $=$ » : Même numérateur : la plus grande a le plus **petit** dénominateur (parts plus grandes), donc $\dfrac{9}{11} < \dfrac{9}{7}$.
   - Si « $>$ » : Même numérateur : la plus grande a le plus **petit** dénominateur (parts plus grandes), donc $\dfrac{9}{11} < \dfrac{9}{7}$.
2. b) $\dfrac{9}{6} \;\square\; \dfrac{11}{6}$ → attendu : $<$ (options : $<$ / $=$ / $>$)
   - Indice : Même dénominateur : compare les numérateurs. Même numérateur : la plus grande a le plus petit dénominateur. À 1 : compare le numérateur au dénominateur.
   - Si « $=$ » : Même dénominateur : on compare les numérateurs ($9 < 11$), donc $\dfrac{9}{6} < \dfrac{11}{6}$.
   - Si « $>$ » : Même dénominateur : on compare les numérateurs ($9 < 11$), donc $\dfrac{9}{6} < \dfrac{11}{6}$.
3. c) $\dfrac{25}{16} \;\square\; 1$ → attendu : $>$ (options : $<$ / $=$ / $>$)
   - Indice : Même dénominateur : compare les numérateurs. Même numérateur : la plus grande a le plus petit dénominateur. À 1 : compare le numérateur au dénominateur.
   - Si « $<$ » : $25$ est plus grand que $16$ : la fraction dépasse $1$, donc $\dfrac{25}{16} > 1$.
   - Si « $=$ » : $25$ est plus grand que $16$ : la fraction dépasse $1$, donc $\dfrac{25}{16} > 1$.

**Corrigé**

> a) Même numérateur : la plus grande a le plus **petit** dénominateur (parts plus grandes), donc $\dfrac{9}{11} < \dfrac{9}{7}$.  
> b) Même dénominateur : on compare les numérateurs ($9 < 11$), donc $\dfrac{9}{6} < \dfrac{11}{6}$.  
> c) $25$ est plus grand que $16$ : la fraction dépasse $1$, donc $\dfrac{25}{16} > 1$.  
> Contrôle : on se représente les parts (plus le dénominateur est grand, plus les parts sont petites).  

Réponse : $\dfrac{9}{11} < \dfrac{9}{7}$ ; $\dfrac{9}{6} < \dfrac{11}{6}$ ; $\dfrac{25}{16} > 1$

**Range ces nombres dans l’ordre croissant (du plus petit au plus grand).**

_Fais glisser les cartes (ou utilise ↑ ↓)._

1. (réponse) → attendu : $\dfrac{1}{2} < \dfrac{5}{6} < \dfrac{13}{12} < \dfrac{3}{2}$
   - Cartes (ordre de départ, croissant demandé) : $\dfrac{5}{6}$ | $\dfrac{1}{2}$ | $\dfrac{3}{2}$ | $\dfrac{13}{12}$
   - Si la paire $\dfrac{5}{6}$ / $\dfrac{1}{2}$ est mal rangée : Compare $\dfrac{5}{6}$ et $\dfrac{1}{2}$ : mets-les au même dénominateur $6$, puis compare les numérateurs.
   - Si la paire $\dfrac{5}{6}$ / $\dfrac{3}{2}$ est mal rangée : Compare $\dfrac{5}{6}$ et $\dfrac{3}{2}$ à $1$ : une fraction dépasse $1$ quand son numérateur est plus grand que son dénominateur.
   - Si la paire $\dfrac{5}{6}$ / $\dfrac{13}{12}$ est mal rangée : Compare $\dfrac{5}{6}$ et $\dfrac{13}{12}$ à $1$ : une fraction dépasse $1$ quand son numérateur est plus grand que son dénominateur.
   - (… 3 autres paires expliquées)
   - Indice : Écris toutes les fractions avec le dénominateur $12$, puis compare les numérateurs.
   - Erreur typique (ordre 3/2 ; 13/12 ; 5/6 ; 1/2) : C’est l’ordre **décroissant** : on demande l’ordre croissant (du plus petit au plus grand).
   - Erreur typique (ordre 1/2 ; 3/2 ; 5/6 ; 13/12) : Tu as rangé selon les numérateurs seulement : les parts n’ont pas la même taille. Mets d’abord toutes les fractions au même dénominateur.

**Corrigé**

> $12$ est un multiple de chaque dénominateur : on écrit toutes les fractions sur $12$.  
> $\dfrac{1}{2} = \dfrac{6}{12}$  
> $\dfrac{5}{6} = \dfrac{10}{12}$  
> $\dfrac{3}{2} = \dfrac{18}{12}$  
> On compare les numérateurs : $6 < 10 < 13 < 18$.  
> Donc $\dfrac{1}{2} < \dfrac{5}{6} < \dfrac{13}{12} < \dfrac{3}{2}$. Celles qui dépassent $1$ (numérateur plus grand que le dénominateur) sont bien du côté des plus grandes.  

Réponse : $\dfrac{1}{2} < \dfrac{5}{6} < \dfrac{13}{12} < \dfrac{3}{2}$
