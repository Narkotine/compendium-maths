## 1. Calculer une image — ★

Adresse : `#/entrainement/08-fonctions/exo?t=image&niv=1&g=1nvjonq` · cours : § 1.2 · Image et antécédents par le calcul

**Calcule des images par $g$.**

Soit $g(x) = -5x + 4$.  

1. a) Calcule $g(6)$. → attendu : $g(6) =$ $-26$
   - Indice : Remplace $x$ par $6$.
   - Erreur typique (réponse -34) : Attention au signe de b.
   - Erreur typique (réponse 34) : Attention au signe du nombre remplacé : mets-le entre parenthèses.
   - Erreur typique (réponse 5) : $-5x$ veut dire $-5 \times x$.
2. b) Calcule $g(-5)$. → attendu : $g(-5) =$ $29$
   - Indice : Remplace $x$ par $(-5)$.
   - Erreur typique (réponse 21) : Attention au signe de b.
   - Erreur typique (réponse -21) : Attention au signe du nombre remplacé : mets-le entre parenthèses.
   - Erreur typique (réponse -6) : $-5x$ veut dire $-5 \times x$.

**Corrigé**

> $g(6) = -5 \times 6 + 4 = -26$  
> $g(-5) = -5 \times (-5) + 4 = 29$  

Réponse : $g(6) = -5 \times 6 + 4 = -26$ ; $g(-5) = -5 \times (-5) + 4 = 29$

## 9. Fonctions linéaires — ★

Adresse : `#/entrainement/08-fonctions/exo?t=lineaire&niv=1&g=1wklbsl` · cours : § 3.3 · Trouver le coefficient

**$h$ est linéaire et $h(-6) = 3$.**

1. a) Calcule le coefficient $a$. → attendu : $a =$ $-0{,}5$
   - Indice : $a = \dfrac{h(-6)}{-6}$.
   - Erreur typique (réponse -2) : Le quotient est à l’envers : image divisée par le nombre de départ.
   - Erreur typique (réponse 9) : Linéaire : on divise, on ne soustrait pas.
2. b) Calcule $h(-1)$. → attendu : $h(-1) =$ $0{,}5$
   - Indice : $h(x) = -0{,}5x$.
3. c) Trouve l’antécédent de $6$. → attendu : $x =$ $-12$
   - Indice : Résous $-0{,}5x = 6$.
   - Erreur typique (réponse -3) : Ça, c’est l’image.

**Corrigé**

> $a = \dfrac{3}{-6} = -0{,}5$, donc $h(x) = -0{,}5x$.  
> $h(-1) = -0{,}5 \times (-1) = 0{,}5$.  
> $-0{,}5x = 6$, donc $x = -12$.  

Réponse : $h(x) = -0{,}5x$

## 10. Fonctions linéaires — ★★

Adresse : `#/entrainement/08-fonctions/exo?t=lineaire&niv=2&g=1l6ghe0` · cours : § 3.3 · Trouver le coefficient

## 12. Fonctions affines — ★★

> $g(2) = 3$ : $-1 \times 2 + b = 3$, donc $b = 5$.  
> Conclusion : $g(x) = -x + 5$. Contrôle : $g(8) = -3$.  

Réponse : $g(x) = -x + 5$

   - Si « $-2$ est un antécédent de $3$ » : C’est l’inverse : c’est $3$ l’antécédent.

**Corrigé**

> a) $g(0) = -5$ : $0$ est l’antécédent, $-5$ l’image.  
> b) L’image de $3$ par $g$ est $-2$ (ou : $3$ est un antécédent de $-2$).  

Réponse : $g(0) = -5$
