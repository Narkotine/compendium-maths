0 Ce qu’on vise

En une phrase : une lettre permet de dire en une seule écriture ce qui est vrai pour tous les nombres ; le calcul littéral sert à écrire des formules, à transformer des expressions et à démontrer.

À la fin de ce chapitre, je sais :

  1. Produire une expression (formule, motif, programme de calcul) et la calculer pour une valeur donnée.
  2. Tester une égalité pour une valeur ; reconnaître si une expression est une somme ou un produit.
  3. Réduire une expression (regrouper les termes semblables).
  4. Développer avec la distributivité simple et double, et factoriser avec un facteur commun.
  5. Utiliser les identités remarquables (a+b)2(a+b)^2(a+b)2, (a−b)2(a-b)^2(a−b)2, (a+b)(a−b)(a+b)(a-b)(a+b)(a−b) dans les deux sens.
  6. Démontrer une propriété avec des lettres (programmes de calcul, pairs et impairs), ou la réfuter par un contre-exemple.

Prérequis. Priorités et règle des signes (chapitre 3, § 3 à 6) ; carrés et puissances (chapitre 4, § 1) ; aire du rectangle et du carré (chapitre 14, § 3).

1 Pourquoi des lettres ?

1.1 Une formule pour toutes les étapes

On construit une rangée de carrés avec des allumettes. Combien faut-il d’allumettes pour 101010 carrés ? pour 100100100 ?

Sur le schéma ci-dessus, on voit la structure : une allumette rouge au départ, puis 333 allumettes bleues par carré. À l’étape nnn, il faut donc 1+3×n1 + 3 \times n1+3×n allumettes.

Exemple guidé 1. Combien faut-il d’allumettes pour 101010 carrés ? pour 100100100 carrés ? Avec 616161 allumettes, combien de carrés peut-on faire ?

Formule : 3n+13n + 13n+1 allumettes pour nnn carrés.
Pour n=10n = 10n=10 : 3×10+1=313 \times 10 + 1 = 313×10+1=31 allumettes. Pour n=100n = 100n=100 : 3×100+1=3013 \times 100 + 1 = 3013×100+1=301 allumettes.
Avec 616161 allumettes : 61−1=6061 - 1 = 6061−1=60 allumettes bleues, soit 60÷3=2060 \div 3 = 2060÷3=20 carrés.

Contrôle. La formule redonne les cas dessinés : n=3n = 3n=3 donne 3×3+1=103 \times 3 + 1 = 103×3+1=10.

Définition. Une expression littérale est une écriture qui contient des nombres, des opérations et des lettres. Chaque lettre désigne un nombre quelconque.

2 Calculer une expression, tester une égalité

Méthode — Calculer une expression pour une valeur.

  1. Remplacer chaque lettre par sa valeur, en rétablissant les signes ×\times×.
  2. Mettre les nombres négatifs entre parenthèses.
  3. Calculer en respectant les priorités : parenthèses, puissances, puis ×\times× et ÷\div÷, puis +++ et −-−.

Exemple guidé 2. Calculer A=2x2−3x+1A = 2x^2 - 3x + 1A=2x2−3x+1 pour x=5x = 5x=5, puis pour x=−2x = -2x=−2.

Pour x=5x = 5x=5 : A=2×52−3×5+1=2×25−15+1=50−15+1=36A = 2 \times 5^2 - 3 \times 5 + 1 = 2 \times 25 - 15 + 1 = 50 - 15 + 1 = 36A=2×52−3×5+1=2×25−15+1=50−15+1=36.
Pour x=−2x = -2x=−2 : A=2×(−2)2−3×(−2)+1=2×4+6+1=15A = 2 \times (-2)^2 - 3 \times (-2) + 1 = 2 \times 4 + 6 + 1 = 15A=2×(−2)2−3×(−2)+1=2×4+6+1=15.

Contrôle. (−2)2=4(-2)^2 = 4(−2)2=4 est positif ; −3×(−2)=+6-3 \times (-2) = +6−3×(−2)=+6.

Erreur fréquente. Calculer 2x22x^22x2 comme (2x)2(2x)^2(2x)2. Pour x=5x = 5x=5 : 2x2=2×25=502x^2 = 2 \times 25 = 502x2=2×25=50, mais (2x)2=102=100(2x)^2 = 10^2 = 100(2x)2=102=100. Le carré ne porte que sur ce qui est juste avant lui.

Tester une égalité. Une égalité avec une lettre peut être vraie pour certaines valeurs et fausse pour d’autres. Pour la tester, on calcule séparément chaque membre.

Égalité 4x−3=2x+54x - 3 = 2x + 54x−3=2x+5. Pour x=4x = 4x=4 : à gauche 4×4−3=134 \times 4 - 3 = 134×4−3=13, à droite 2×4+5=132 \times 4 + 5 = 132×4+5=13 : vraie.
Pour x=1x = 1x=1 : à gauche 111, à droite 777 : fausse.

Une égalité vraie pour toutes les valeurs s’appelle une identité (par exemple 2x+3x=5x2x + 3x = 5x2x+3x=5x). Un seul cas où elle est fausse suffit à prouver que ce n’est pas une identité : c’est un contre-exemple (§ 8).

3 Somme ou produit ?

La nature d’une expression est donnée par la dernière opération qu’on effectuerait pour la calculer.

Expression Dernière opération Nature
3x+23x + 23x+2 l’addition somme (de deux termes)
5(x+4)5(x + 4)5(x+4) la multiplication produit (de deux facteurs)
(x+1)(x−2)(x + 1)(x - 2)(x+1)(x−2) la multiplication produit
x2+1x^2 + 1x2+1 l’addition somme
2(x+1)+32(x + 1) + 32(x+1)+3 l’addition somme

Cette distinction est essentielle : développer transforme un produit en somme ; factoriser transforme une somme en produit.

4 Réduire une expression

Réduire, c’est écrire une expression avec le moins de termes possible. On regroupe les termes semblables (même partie littérale), comme on regroupe des tuiles de même forme.

Propriété. ax+bx=(a+b)xax + bx = (a + b)xax+bx=(a+b)x : on additionne les coefficients. Par exemple 5x+3x=8x5x + 3x = 8x5x+3x=8x et 7x2−2x2=5x27x^2 - 2x^2 = 5x^27x2−2x2=5x2. Les termes en xxx, en x2x^2x2 et les nombres seuls restent séparés.

Exemple guidé 3. Réduire B=3x2+5x−7−x2+2x+4B = 3x^2 + 5x - 7 - x^2 + 2x + 4B=3x2+5x−7−x2+2x+4.

On regroupe : termes en x2x^2x2 : 3x2−x2=2x23x^2 - x^2 = 2x^23x2−x2=2x2 ; termes en xxx : 5x+2x=7x5x + 2x = 7x5x+2x=7x ; nombres : −7+4=−3-7 + 4 = -3−7+4=−3.
B=2x2+7x−3B = 2x^2 + 7x - 3B=2x2+7x−3.

Contrôle. Pour x=1x = 1x=1 : l’expression de départ vaut 3+5−7−1+2+4=63 + 5 - 7 - 1 + 2 + 4 = 63+5−7−1+2+4=6, la forme réduite 2+7−3=62 + 7 - 3 = 62+7−3=6.

Erreur fréquente. Écrire 3x+2=5x3x + 2 = 5x3x+2=5x. On ne peut pas additionner des xxx et des unités (tuiles différentes). Contre-exemple : pour x=2x = 2x=2, 3x+2=83x + 2 = 83x+2=8 mais 5x=105x = 105x=10. De même, x+x=2xx + x = 2xx+x=2x mais x×x=x2x \times x = x^2x×x=x2.

5 Développer

5.1 La distributivité simple

Le rectangle ci-dessous a pour hauteur 333 et pour largeur x+4x + 4x+4. On calcule son aire de deux façons : d’un coup, 3(x+4)3(x + 4)3(x+4) ; ou en deux morceaux, 3x+123x + 123x+12.

Propriété (distributivité simple). Pour tous nombres kkk, aaa, bbb : k(a+b)=ka+kbk(a−b)=ka−kbk(a + b) = ka + kb \qquad k(a - b) = ka - kbk(a+b)=ka+kbk(a−b)=ka−kb

Développer, c’est transformer un produit en somme. Le facteur devant la parenthèse multiplie chaque terme de la parenthèse, avec son signe.

4(x−3)=4x−124(x - 3) = 4x - 124(x−3)=4x−12 ;   −2(3x−5)=−6x+10\;-2(3x - 5) = -6x + 10−2(3x−5)=−6x+10 ;   x(x+7)=x2+7x\;x(x + 7) = x^2 + 7xx(x+7)=x2+7x.
Un signe −-− devant une parenthèse, c’est −1×-1 \times−1× : −(5−4x)=−5+4x-(5 - 4x) = -5 + 4x−(5−4x)=−5+4x (on change tous les signes).

Erreur fréquente. Ne multiplier que le premier terme : 3(x+4)=3x+43(x + 4) = 3x + 43(x+4)=3x+4 est faux. Contre-exemple : pour x=1x = 1x=1, 3×5=153 \times 5 = 153×5=15 mais 3+4=73 + 4 = 73+4=7. Autre piège : −2(x−5)=−2x−10-2(x - 5) = -2x - 10−2(x−5)=−2x−10 est faux, car −2×(−5)=+10-2 \times (-5) = +10−2×(−5)=+10.

5.2 La double distributivité

Le grand rectangle ci-dessous a pour côtés x+3x + 3x+3 et x+5x + 5x+5. Il est formé de quatre rectangles : son aire est la somme de quatre produits.

Propriété (double distributivité). Pour tous nombres aaa, bbb, ccc, ddd : (a+b)(c+d)=ac+ad+bc+bd(a + b)(c + d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd

Exemple guidé 4. Développer et réduire C=(2x−1)(x+3)C = (2x - 1)(x + 3)C=(2x−1)(x+3).

Réflexion. Chaque terme de la première parenthèse (2x2x2x et −1-1−1) multiplie chaque terme de la seconde (xxx et 333) : quatre produits, avec leurs signes.

C=2x×x+2x×3+(−1)×x+(−1)×3C = 2x \times x + 2x \times 3 + (-1) \times x + (-1) \times 3C=2x×x+2x×3+(−1)×x+(−1)×3
C=2x2+6x−x−3C = 2x^2 + 6x - x - 3C=2x2+6x−x−3
C=2x2+5x−3C = 2x^2 + 5x - 3C=2x2+5x−3.

Contrôle. Pour x=1x = 1x=1 : (2−1)(1+3)=4(2 - 1)(1 + 3) = 4(2−1)(1+3)=4 et 2+5−3=42 + 5 - 3 = 42+5−3=4. On teste toujours avec une valeur simple.

Méthode — Développer et réduire.

  1. Écrire tous les produits (un facteur simple : autant de produits que de termes ; deux parenthèses de deux termes : 444 produits).
  2. Calculer chaque produit avec son signe.
  3. Réduire, puis contrôler avec x=1x = 1x=1 (ou x=2x = 2x=2).

6 Factoriser

Factoriser, c’est faire le chemin inverse du développement : transformer une somme en produit, en repérant un facteur commun à tous les termes.

Propriété. ka+kb=k(a+b)ka + kb = k(a + b)ka+kb=k(a+b) et ka−kb=k(a−b)ka - kb = k(a - b)ka−kb=k(a−b).

Exemple guidé 5. Factoriser D=6x+9D = 6x + 9D=6x+9, puis E=2x2+6xE = 2x^2 + 6xE=2x2+6x.

D=3×2x+3×3=3(2x+3)D = 3 \times 2x + 3 \times 3 = 3(2x + 3)D=3×2x+3×3=3(2x+3).
E=2x×x+2x×3=2x(x+3)E = 2x \times x + 2x \times 3 = 2x(x + 3)E=2x×x+2x×3=2x(x+3).

Contrôle. On redéveloppe : 3(2x+3)=6x+93(2x + 3) = 6x + 93(2x+3)=6x+9 ✓ et 2x(x+3)=2x2+6x2x(x + 3) = 2x^2 + 6x2x(x+3)=2x2+6x ✓.

Le facteur commun peut être une parenthèse entière :

(x+1)(2x+3)+(x+1)(x−4)=(x+1)[(2x+3)+(x−4)]=(x+1)(3x−1)(x + 1)(2x + 3) + (x + 1)(x - 4) = (x + 1)\big[(2x + 3) + (x - 4)\big] = (x + 1)(3x - 1)(x+1)(2x+3)+(x+1)(x−4)=(x+1)[(2x+3)+(x−4)]=(x+1)(3x−1).

Erreur fréquente. Factoriser « à moitié » : 2x+6=2(x+6)2x + 6 = 2(x + 6)2x+6=2(x+6) est faux, car 2(x+6)=2x+122(x + 6) = 2x + 122(x+6)=2x+12. Le bon résultat est 2(x+3)2(x + 3)2(x+3). Toujours redévelopper pour vérifier.

Méthode — Factoriser.

  1. Écrire chaque terme comme un produit faisant apparaître le facteur commun (nombre, lettre ou parenthèse).
  2. Mettre ce facteur en tête, et entre crochets ce qui reste de chaque terme.
  3. Réduire l’intérieur, puis redévelopper pour contrôler.

7 Identités remarquables (★★)

Ce sont trois développements, au programme de 3e, qui reviennent si souvent qu’on les apprend par cœur, dans les deux sens.

Propriété (identités remarquables). Pour tous nombres aaa et bbb : (a+b)2=a2+2ab+b2(a−b)2=a2−2ab+b2(a+b)(a−b)=a2−b2(a + b)^2 = a^2 + 2ab + b^2 \qquad (a - b)^2 = a^2 - 2ab + b^2 \qquad (a + b)(a - b) = a^2 - b^2(a+b)2=a2+2ab+b2(a−b)2=a2−2ab+b2(a+b)(a−b)=a2−b2

Pourquoi 2ab2ab2ab ? Le carré de côté a+ba + ba+b est formé de quatre morceaux : un carré a2a^2a2, un carré b2b^2b2 et deux rectangles ababab.

Pour la troisième, on enlève à un carré de côté aaa un petit carré de côté bbb, puis on recolle les deux morceaux en un rectangle de côtés a+ba + ba+b et a−ba - ba−b : l’aire n’a pas changé.

Exemple guidé 6. a) Développer (2x−3)2(2x - 3)^2(2x−3)2. b) Factoriser x2−25x^2 - 25x2−25 et 4x2+12x+94x^2 + 12x + 94x2+12x+9.

Réflexion. a) C’est (a−b)2(a - b)^2(a−b)2 avec a=2xa = 2xa=2x et b=3b = 3b=3. b) x2−25=x2−52x^2 - 25 = x^2 - 5^2x2−25=x2−52 est une différence de deux carrés ; 4x2+12x+9=(2x)2+2×2x×3+324x^2 + 12x + 9 = (2x)^2 + 2 \times 2x \times 3 + 3^24x2+12x+9=(2x)2+2×2x×3+32.

a) (2x−3)2=(2x)2−2×2x×3+32=4x2−12x+9(2x - 3)^2 = (2x)^2 - 2 \times 2x \times 3 + 3^2 = 4x^2 - 12x + 9(2x−3)2=(2x)2−2×2x×3+32=4x2−12x+9.
b) x2−25=x2−52=(x+5)(x−5)x^2 - 25 = x^2 - 5^2 = (x + 5)(x - 5)x2−25=x2−52=(x+5)(x−5).
b)\phantom{b)}b) 4x2+12x+9=(2x)2+2×2x×3+32=(2x+3)24x^2 + 12x + 9 = (2x)^2 + 2 \times 2x \times 3 + 3^2 = (2x + 3)^24x2+12x+9=(2x)2+2×2x×3+32=(2x+3)2.

Contrôle. Pour x=1x = 1x=1 : (2−3)2=1(2 - 3)^2 = 1(2−3)2=1 et 4−12+9=14 - 12 + 9 = 14−12+9=1 ✓ ; 1−25=−241 - 25 = -241−25=−24 et 6×(−4)=−246 \times (-4) = -246×(−4)=−24 ✓.

Erreur fréquente. (a+b)2=a2+b2(a + b)^2 = a^2 + b^2(a+b)2=a2+b2 est faux. Contre-exemple : (3+4)2=49(3 + 4)^2 = 49(3+4)2=49, alors que 32+42=253^2 + 4^2 = 2532+42=25. Il manque 2×3×4=242 \times 3 \times 4 = 242×3×4=24 (les deux rectangles verts du schéma). De même, (a−b)2≠a2−b2(a - b)^2 \neq a^2 - b^2(a−b)2=a2−b2.

Astuce (calcul mental). 1012=(100+1)2=10 000+200+1=10 201101^2 = (100 + 1)^2 = 10\,000 + 200 + 1 = 10\,2011012=(100+1)2=10000+200+1=10201 ;   99×101=(100−1)(100+1)=10 000−1=9 999\;99 \times 101 = (100 - 1)(100 + 1) = 10\,000 - 1 = 9\,99999×101=(100−1)(100+1)=10000−1=9999.

8 Programmes de calcul et démonstrations

8.1 Tester, conjecturer, prouver

Un programme de calcul est une suite d’instructions appliquée à un nombre. Avec une lettre, on peut prévoir le résultat pour tous les nombres.

Exemple guidé 7. On applique le programme ci-dessus. a) Quel résultat obtient-on avec 222 ? avec 555 ? b) Montrer que le résultat est toujours égal à 6x+96x + 96x+9, où xxx est le nombre choisi. c) Quel nombre faut-il choisir pour obtenir 454545 ?

a) Avec 222 : 2+3=52 + 3 = 52+3=5 ; 52=255^2 = 2552=25 ; 25−22=2125 - 2^2 = 2125−22=21. Avec 555 : 82−52=64−25=398^2 - 5^2 = 64 - 25 = 3982−52=64−25=39.
b) Avec xxx : (x+3)2−x2=x2+6x+9−x2=6x+9(x + 3)^2 - x^2 = x^2 + 6x + 9 - x^2 = 6x + 9(x+3)2−x2=x2+6x+9−x2=6x+9. Le résultat est toujours 6x+96x + 96x+9.
c) 6x+9=456x + 9 = 456x+9=45 donne 6x=366x = 366x=36, donc x=6x = 6x=6 (voir le chapitre 7). Contrôle : 92−62=81−36=459^2 - 6^2 = 81 - 36 = 4592−62=81−36=45.

Contrôle. 6×2+9=216 \times 2 + 9 = 216×2+9=21 et 6×5+9=396 \times 5 + 9 = 396×5+9=39 : on retrouve les résultats du a).

Erreur fréquente. Croire qu’essayer quelques nombres suffit à prouver. Des exemples permettent de conjecturer ; seule l’écriture avec une lettre prouve pour tous les nombres.

8.2 Pairs, impairs, multiples

À retenir. Si nnn est un nombre entier : un nombre pair s’écrit 2n2n2n ; un nombre impair s’écrit 2n+12n + 12n+1 ; deux entiers consécutifs s’écrivent nnn et n+1n + 1n+1 ; un multiple de 3 s’écrit 3n3n3n.

Exemple guidé 8. Montrer que la somme de trois entiers consécutifs est toujours un multiple de 333.

Trois entiers consécutifs s’écrivent nnn, n+1n + 1n+1 et n+2n + 2n+2, où nnn est un entier.
Leur somme vaut n+(n+1)+(n+2)=3n+3=3(n+1)n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1)n+(n+1)+(n+2)=3n+3=3(n+1).
C’est 333 fois un entier : c’est un multiple de 333.

Contrôle. 7+8+9=24=3×87 + 8 + 9 = 24 = 3 \times 87+8+9=24=3×8, et 8=7+18 = 7 + 18=7+1 ✓.

Le contre-exemple. Pour montrer qu’une affirmation est fausse, un seul exemple qui ne marche pas suffit. « Le carré d’un nombre est toujours plus grand que ce nombre » est faux : 0,52=0,250{,}5^2 = 0{,}250,52=0,25, plus petit que 0,50{,}50,5.

9 Mini-synthèse

À retenir.

  • 3x=3×x3x = 3 \times x3x=3×x ; x2=x×xx^2 = x \times xx2=x×x ; on remplace une lettre par un nombre en rétablissant les ×\times× et les parenthèses.
  • Réduire : on regroupe les termes semblables (5x+3x=8x5x + 3x = 8x5x+3x=8x), jamais des xxx avec des x2x^2x2 ou des nombres.
  • Développer : k(a+b)=ka+kbk(a + b) = ka + kbk(a+b)=ka+kb ; (a+b)(c+d)=ac+ad+bc+bd(a + b)(c + d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd ; signes compris ; contrôle avec x=1x = 1x=1.
  • Factoriser : repérer le facteur commun, ka+kb=k(a+b)ka + kb = k(a + b)ka+kb=k(a+b) ; redévelopper pour contrôler.
  • Identités : (a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2 ; (a−b)2=a2−2ab+b2(a - b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2 ; (a+b)(a−b)=a2−b2(a + b)(a - b) = a^2 - b^2(a+b)(a−b)=a2−b2.
  • Prouver : avec une lettre (pair 2n2n2n, impair 2n+12n + 12n+1) ; réfuter : un contre-exemple.
